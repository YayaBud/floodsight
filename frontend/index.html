Solvers

FloodSight runs a 2D finite-volume shallow-water solver. It is checked against the Ritter analytical dam-break solution and a mass-closure ledger. Its lake-at-rest benchmark is currently passing on a configuration where the lake drains off the domain edge, and a lake bounded by dry terrain does not stay at rest — so treat depths near a standing pool as provisional. Two other solver arms exist in the repository; their real wiring status is below.

Runs on every simulation

FloodSight 2D SWE

Audusse hydrostatic reconstruction, MUSCL with minmod, SSP-RK2, Kurganov–Petrova desingularisation. Checked on lake-at-rest, mass closure, Ritter RMSE, wave speed and front location.

SWE-SPH, 1D (PS i)

Depth-averaged smoothed-particle hydrodynamics, self-contained in sph_swe.py. It runs the analytical Ritter benchmark, and that result is real. The per-scenario thalweg comparison against 2D FV is not run: the two arms are not given the same event (the 2D arm no longer takes a forcing hydrograph at all — discharge is measured at the breach opening, not prescribed), they average depth over different spatial support, and the 2D arm reports a run maximum against the SPH arm’s final instant. An RMSE between those is not a solver-agreement number, so none is shown.

Delft3D-FLOW

Structured finite-difference solver, Deltares, GPLv3. Delft3D has never been run in this project. The card is kept to name the solver as future work, not to report a result.

About

NDSA has a plan for all 6,628 specified dams. Nobody has a plan for the dam that formed last Tuesday. We build one in twenty minutes from open data.

What is new here

  • Impoundments nobody registered — landslide dams, moraine lakes, river blockages. No DHARMA record, no emergency action plan, no gauge.
  • Roads that close over time — the road graph is cut as a function of simulation time, not once at the end.
  • Three breach estimates, not one — Froehlich, Von Thun & Gillette and MacDonald carried as a range.

What already exists

  • RBSD — dam-break population dashboard for 6,628 specified dams.
  • C-FLOOD — 48-hour inundation forecast at village level.
  • DHARMA — dam register and health monitoring.
  • SACHET — the national CAP alert pipeline.

Where the data comes from

  • Terrain: Copernicus GLO-30, 27.9 m at this latitude
  • People: GHS-POP 3 arc-second, area-conserving resample
  • Buildings and roads: OpenStreetMap
  • Settlements: OSM place nodes

Honest limits

  • Roughness is inferred from population density, not land cover.
  • Only the middle breach estimate is carried through to roads and people.
